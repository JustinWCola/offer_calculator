# Offer Joker

像素牌桌风格的 Offer 比较计算器，使用 React 和 Vite。支持最多十份 Offer，计算收入、税费、个人五险一金、权益兑现折扣、假期与加权工时。

在线地址：https://justinwcola.github.io/offer_joker/

## 开发与发布

需要 Node.js 22.12 以上；云环境已验证 Node.js 24 和 npm 11。

```sh
cd /workspace/offer_calculator
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run dev
```

本地开发进入实际 checkout 目录执行 `npm ci` 即可。开发服务监听 `0.0.0.0:5173`，严格检查端口冲突；云环境重启后需重新启动进程。不需要后端、数据库、环境变量或应用密钥。

```sh
npm test        # 计算、假期、默认值、排序、火焰与数值步进测试
npm run build   # 生成 dist/
npm run preview # 在 4173 端口验证生产构建
```

推送到 `main` 或运行 `Deploy GitHub Pages` 工作流会安装依赖、测试、构建并部署。Settings → Pages 的 Source 使用 GitHub Actions。资源路径支持仓库子路径。在线网站独立于开发服务器。

## 使用

- 首次无保存数据时显示一个参考 Offer。新建／重置报价的薪资待填写，12 薪、额外收入为 0、每周 5 天每天 9 小时、无周末加班，年假／法定假日／带薪病假默认为 5／13／3 天。参考示例采用原计算器的 9.5 万月薪 × 15、40 万签字费与 60 万股票。
- 顶部卡牌代表报价，点击选择；牌堆用于新增，拖动卡牌回牌堆删除，删除可撤销。最多十张牌，数量增加时重叠排列，尺寸不因牌数缩小。复制和可撤销的重置按钮在编辑区顶部。
- 排序有自定义与自动两种模式。选择依据开启自动排序，输入变化立即更新排列；拖动或 Alt + 左右方向键切换为自定义，并采用当前显示顺序。牌面显示所选排序指标。
- 固定收入包含月基本工资、月现金补贴，按各自发放月数合计；浮动收入包含年终奖、签字费、股票、期权等，按兑现系数折算。展开行共用表头；「单／综／股／免」符号表示计税方式。
- 工作城市在税费栏。六项个人缴费参数排成两行三列，税前扣除直接显示；上下限与固定医疗费可展开。工时、收入和税费拆分在底部独立明细面板。
- 编辑区顶部显示等效税后年收入与时薪、税前总包、个人所得税、个人五险一金和税后总包。只有编辑内容滚动。宽屏三栏、中屏两栏、手机单栏。
- 选项可关闭动效、背景或 CRT，切换紧凑金额单位，导出结果或恢复参考示例。紧凑单位使年度金额用万元、月收入输入用千元；实际计算、保存和导出仍使用元。
- 数据仅保存在当前浏览器的 localStorage。已有输入保留；恢复示例会替换当前报价。删除和重置的撤销仅在当前会话有效。空牌槽刷新后仍为空。
- 鼠标、触摸和键盘均可操作；下拉选项支持方向键、Home/End、Enter 和 Escape。无效输入可定位，隐藏输入会自动展开。

## 计算规则

收入与税费计算参考 [sherry-roar/offer-calculate](https://sherry-roar.github.io/offer-calculate/)，假期抵扣参考 [zippland/worth-calculator](https://github.com/zippland/worth-calculator)。

```text
税后价值 = 各项收入按兑现系数折算之和 − 名义收入对应税费 − 个人五险一金
加权周工时 = 正常工作日工时 + 1.5 × 工作日超过 8 小时的工时 + 2 × 周末工时
计划全年工作日 =（每周工作日 + 每周周末加班日）× 52
假期折算 = 年假 + 法定假日 + 0.6 × 带薪病假
全年工作日 = max(计划全年工作日 − 假期折算, 0)
加权全年工时 = 加权周工时 × 52 × 全年工作日 ÷ 计划全年工作日
税后 855 等效 = 税后价值 × 成长系数 × 个人偏好系数 × 2080 ÷ 加权全年工时
等效税后时薪 = 税后 855 等效 ÷ 2080
```

所有结果使用未取整精度。假期应填写占用原计划工作日的天数，避免重复扣除；带薪病假系数按参考代码实际使用的 0.6。全年工作日须大于 0。旧数据缺少假期字段时按 0 天保留原结果。假期不改变税费；未计算通勤。

税后价值包含折算权益与福利，不等于现金到账。签字费按本年收入处理，股权单独计税有适用条件。北京缴费上下限采用历史示例，其他城市需自行确认基数；所有参数均可编辑。评级沿用参考项目的娱乐分档。

## 视觉与来源

数字、乘号和标题使用 Daniel Linssen 的 M6X11，中文使用 Cubic 11。牌面为白色底纹，彩色蜡封位于右上角和报价名称后。原始 `.fs` 参考文件与多彩牌面实现不在当前仓库中；运行所需的 WebGL2 背景、火焰代码位于 `src/shaders/`。CRT 采用 CSS 扫描线与暗角，避免扭曲表单。

[Balatro-Button](https://github.com/mininxd/Balatro-Button) 是早期火焰实现的参考来源，其说明与 Apache-2.0 许可证保留。当前火焰由用户提供的 LÖVE 着色器转换而来。设计规则和火焰阈值见 [DESIGN.md](DESIGN.md)，来源与完整许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
