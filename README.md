# Offer 牌桌

一个像素牌桌风格的 Offer 比较计算器，使用 React 和 Vite。支持最多六份 Offer：年收入、税费、个人五险一金、权益兑现折扣及加权工时共同决定等效税后时薪。起始的两份 Offer 为虚构、可编辑示例。

在线地址：https://justinwcola.github.io/offer_calculator/

## 网页发布

推送到 `main` 或手动运行 `Deploy GitHub Pages` 工作流，会执行计算测试、生产构建并部署 `dist/` 到 GitHub Pages。仓库的 Settings → Pages 需要将 Source 设置为 GitHub Actions。构建使用相对资源路径，支持仓库子路径访问。

云环境重启后开发服务器需要重新启动；在线网页独立于开发服务器运行。

## 开发

需要 Node.js 22.12 以上（此云环境已验证 Node.js 24.19.0、npm 11.9.0）。

```sh
cd /workspace/offer_calculator
npm ci --cache /workspace/.cache/npm --no-audit --no-fund
npm run dev
```

开发服务器端口为 5173，监听所有接口并严格检查端口冲突。仓库内不需要数据库、后端服务、环境变量或密钥。依赖与构建产物保存在 `node_modules/`、`dist/`；服务进程在新任务中需重新启动。

本地其他位置开发时，进入实际 checkout 目录，使用 `npm ci` 安装即可，不必指定云环境的缓存路径。

```sh
npm test       # Node 内置测试：税率边界、已知结果、缴费、工时、非法输入
npm run build # 生成 dist/ 静态文件
npm run preview # 启动生产构建的本地验证服务器，端口 4173
```

## 使用

- 名称、城市和六项结果集中在编辑区顶部：等效税后年收入与时薪、税前总包、个人所得税、个人五险一金及税后总包。完整文字明细另含税前等效年收入、平均月税后价值、收入和税费拆分。
- 月固定工资和年终奖分别是两个收入表的首行；月工资下展开月补贴，一次性补贴与权益在年终奖下展开，各组始终共用同一表头。工作城市位于税费栏；缴纳月数及五项比例排成两行三列，医疗固定费放在「缴费上下限与税前扣除」。个税和缴费明细放在底部「完整结果与税费明细」。数值标签在框外，上下箭头支持调整金额、月数、工时和兑现系数。
- 顶部牌槽只放 Offer 卡牌；牌堆独立放在槽外，Offer 数量显示在左侧。评价以彩色印戳贴在结果栏上方。点击后卡牌向上抽出，下方编辑区只显示选中的报价；选择和输入会自动保存。
- 「收入」「工时」「税费」在宽屏三栏、中等屏幕两栏、手机单栏展示。仅编辑内容滚动，顶部结果与手牌始终可见；更多参数折叠收起。蓝色底数 × 红色倍率用于月薪 × 发薪月数、工时 × 天数、收入兑现等实际乘法；税费与结果明细用文字展示。
- 发展前景使用原参考项目的五档下拉选项，生活偏好使用喜欢程度的五档选项；历史输入的其他系数保留为当前值选项，不自动覆盖。
- 两数相乘后的乘积决定蓝红等宽计分框的火焰等级；年度金额按 10 万、30 万、50 万，周工时按 40、50、60 小时分级。零或非法乘积不着火，相同单位的相同乘积拥有相同等级；火焰只表达数值大小，不评价 Offer 好坏。左侧选项可以关闭动画或显示公式注释，并尊重系统减少动画偏好。
- 左侧「手牌排序」支持自定义顺序，及按时薪、税后年收入、税前总包、月薪、工时和名称排序。直接点击「自定义／手动／自动」切换模式，不需要先选择排序依据再勾选开关。手动模式进入或改变依据／方向时排一次，编辑输入后点「重新排序」才更新；自动模式随输入实时重排。拖动手牌会采用当前显示顺序、切换到自定义并关闭自动排序；Alt + 左右方向键也能移动手牌。点击「自定义」恢复最后保存的自定义排列，返回指标模式时记住上次排序依据。缺失数值的报价排在末尾，当前编辑对象保持不变。
- 点击 Offer 槽旁的牌堆，或把它拖到牌槽／编辑区，新增并选中一份 Offer。编辑区标题旁的复制按钮可复制当前报价。
- 拖动手牌时牌堆会显示删除提示，悬停后提示「松开删除」。把手牌拖回牌堆删除，也可以点击编辑区标题旁的删除按钮；支持撤销，包括最后一张。全部删除后可以重新抽牌，刷新不会自动补回示例。
- 窄屏保留牌槽旁的单个牌堆。点击、鼠标拖动和触摸拖动均可操作；键盘可用 Tab/Enter 选择与抽弃牌，像素下拉菜单支持方向键、Home/End、Enter 和 Escape。
- 参数仅保存在当前浏览器的 localStorage，不上传到服务器。左侧选项中可以导出比较结果或恢复示例（会替换当前输入）。

## 计算方法与限制

计算模块来自 [sherry-roar 的 Offer 等效薪资计算器](https://sherry-roar.github.io/offer-calculate/)，保留原始计算规则。源码位于其 [GitHub Pages 仓库](https://github.com/sherry-roar/sherry-roar.github.io/tree/main/offer-calculate)，来源及 MIT 授权全文见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

```text
折算税后价值 = 各项收入按兑现比例折算之和 − 名义收入对应税费 − 个人五险一金
加权周工时 = 正常工作日工时 + 1.5 × 工作日超出8小时的工时 + 2 × 周末工时
税后855等效 = 折算税后价值 × 成长系数 × 生活偏好系数 × 40 ÷ 加权周工时
等效税后时薪 = 税后855等效 ÷ 2080
```

税后价值包含权益与福利，不等同于现金到账；全年按 52 周比较，没有单独计算假期和通勤。签字费为本年一次性收入。股权单独计税需满足适用政策条件。北京使用 2025 年社保及 2025–2026 年度公积金历史参数，其他城市只提供比例示例，需要自行确认缴费基数上下限。分档为参考项目的娱乐性比较标签。

界面按 Balatro 截图采用深灰面板、绿色牌桌、红色帮助与橙色选项按钮的配色，包含侧栏、顶部 Offer 手牌槽、单份编辑区、蓝红乘法计分器、参考 Balatro-Button 着色器的像素火焰及合并牌堆。检索参考、设计说明及数值映射见 [DESIGN.md](DESIGN.md)。像素图标和牌桌背景为原创，Cubic 11 字体完整许可随仓库分发。
